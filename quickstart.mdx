# Quickstart

This guide walks you through creating your first voice agent using the Omnia Voice API.

## Prerequisites

Before you begin, make sure you have:

1. An Omnia Voice account ([Sign up here](https://dashboard.omnia-voice.com))
2. An API key ([Generate one in the dashboard](https://dashboard.omnia-voice.com/dashboard/api-keys))

## Step 1: Get Your API Key

Navigate to the [API Keys](https://dashboard.omnia-voice.com/dashboard/api-keys) section in your dashboard and create a new API key.

<Warning>
  Keep your API key secure and never expose it in client-side code.
</Warning>

## Step 2: Get Available Voices

First, let's see what voices are available:

<CodeGroup>
```bash cURL
curl https://dashboard.omnia-voice.com/api/v1/voices \
  -H "X-API-Key: YOUR_API_KEY"
```

```javascript Node.js
const response = await fetch('https://dashboard.omnia-voice.com/api/v1/voices', {
  headers: { 'X-API-Key': 'YOUR_API_KEY' }
});
const voices = await response.json();
```

```python Python
import requests

response = requests.get(
    'https://dashboard.omnia-voice.com/api/v1/voices',
    headers={'X-API-Key': 'YOUR_API_KEY'}
)
voices = response.json()
```
</CodeGroup>

## Step 3: Get Available Languages

```bash
curl https://dashboard.omnia-voice.com/api/v1/languages \
  -H "X-API-Key: YOUR_API_KEY"
```

## Step 4: Create Your First Agent

Now let's create a voice agent:

<CodeGroup>
```bash cURL
curl -X POST https://dashboard.omnia-voice.com/api/v1/agents \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Customer Support Agent",
    "description": "A friendly customer support representative",
    "status": "ACTIVE",
    "config": {
      "languageId": "YOUR_LANGUAGE_ID",
      "voiceId": "YOUR_VOICE_ID",
      "greeting": "Hello! Thank you for calling. How can I help you today?",
      "basePrompt": "You are a friendly and professional customer support agent.",
      "context": "You work for a technology company that provides cloud services.",
      "customInstructions": "Always be polite and try to resolve issues quickly.",
      "recordingEnabled": true
    }
  }'
```

```javascript Node.js
const response = await fetch('https://dashboard.omnia-voice.com/api/v1/agents', {
  method: 'POST',
  headers: {
    'X-API-Key': 'YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    name: 'Customer Support Agent',
    description: 'A friendly customer support representative',
    status: 'ACTIVE',
    config: {
      languageId: 'YOUR_LANGUAGE_ID',
      voiceId: 'YOUR_VOICE_ID',
      greeting: 'Hello! Thank you for calling. How can I help you today?',
      basePrompt: 'You are a friendly and professional customer support agent.',
      recordingEnabled: true
    }
  })
});
```
</CodeGroup>

<Accordion title="Example Response">
```json
{
  "id": "agent-123",
  "name": "Customer Support Agent",
  "status": "ACTIVE",
  "createdAt": "2025-01-01T00:00:00Z"
}
```
</Accordion>

## Step 5: Test Your Agent

Test your agent using WebRTC:

```bash
curl -X POST https://dashboard.omnia-voice.com/api/v1/calls/create \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "agentId": "YOUR_AGENT_ID",
    "connectionType": "webrtc"
  }'
```

This returns a WebSocket URL you can use to connect and start a voice conversation.

## Step 6: Add Tools (Optional)

Tools allow your agent to perform actions. Here's how to create a simple tool:

```bash
curl -X POST https://dashboard.omnia-voice.com/api/v1/agent-tools \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "http",
    "name": "Book Appointment",
    "modelToolName": "bookAppointment",
    "description": "Books an appointment for the caller",
    "baseUrlPattern": "https://your-api.com/appointments",
    "httpMethod": "POST",
    "dynamicParameters": {
      "date": {
        "location": "body",
        "schema": {
          "type": "string",
          "description": "Appointment date"
        },
        "required": true
      }
    }
  }'
```

Then assign it to your agent:

```bash
curl -X POST https://dashboard.omnia-voice.com/api/v1/agents/YOUR_AGENT_ID/tools \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "toolIds": ["YOUR_TOOL_ID"]
  }'
```
