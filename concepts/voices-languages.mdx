# Voices & Languages

Omnia Voice supports 100+ voices across 26 languages, allowing you to create agents that speak naturally in your customers' preferred language.

## Listing Voices

```bash
curl https://dashboard.omnia-voice.com/api/v1/voices \
  -H "X-API-Key: YOUR_API_KEY"
```

Filter by language:

```bash
curl https://dashboard.omnia-voice.com/api/v1/voices?languageCode=en \
  -H "X-API-Key: YOUR_API_KEY"
```

## Listing Languages

```bash
curl https://dashboard.omnia-voice.com/api/v1/languages \
  -H "X-API-Key: YOUR_API_KEY"
```

## Voice Characteristics

Each voice has unique characteristics:

- **Gender**: Male, Female
- **Tone**: Professional, Friendly, Calm, Energetic
- **Age**: Young, Middle-aged, Senior
- **Accent**: Regional variations

## Choosing the Right Voice

Consider your use case:

| Use Case | Recommended Voice Style |
|----------|------------------------|
| Customer Support | Friendly, Patient |
| Sales | Energetic, Confident |
| Medical | Calm, Professional |
| Finance | Professional, Trustworthy |

## Preview Voices

Each voice includes a preview URL. Use the dashboard to listen to samples before selecting.

```json
{
  "id": "voice_sarah",
  "name": "Sarah",
  "description": "Friendly female voice with American accent",
  "previewUrl": "https://...",
  "languageCode": "en-US"
}
```
